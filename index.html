CSS Proposed

October 10, 1994

{

Typographic content becomes designable

 

Håkon Wium Lie formally proposed Cascading Style Sheets to the web standards community. This was the first public articulation of separating content from presentation. CSS was standardized through the World Wide Web Consortium.

CSS was proposed and developed largely through the work of Håkon Wium Lie, and standardized through the World Wide Web Consortium.

 

This is the moment when typographic design truly becomes possible on the web:

  • font families
  • line-height
  • spacing
  • alignment
  • hierarchy
  • layout control

Before CSS typography was mostly browser defaults.

After CSS typography became a design system.

This is the real birth of web typography as a design discipline.

}
